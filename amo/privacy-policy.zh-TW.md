# 隱私權政策

**書籤預覽**（Bookmark Preview）

最後更新：2026-10-08

## 一句話版本

這個擴充套件**不收集任何資料**，也沒有伺服器。你的資料留在你自己的裝置上；會同步的部分存在你自己的 Firefox 帳號裡 —— 開發者一律拿不到。

## 我們收集什麼

沒有。這個擴充套件：

- 不做任何遙測、統計或使用行為記錄。
- 沒有後端伺服器，也沒有帳號。
- 不會把你的書籤、瀏覽記錄、預覽圖或主密碼傳給開發者或任何第三方。

這與擴充套件在 `manifest.json` 中的宣告一致：

```json
"data_collection_permissions": { "required": ["none"] }
```

## 資料存在哪裡

全部存在你的瀏覽器本機儲存空間裡：

| 資料 | 存放位置 |
|---|---|
| 預覽圖（網頁截圖、封面圖與網站圖示） | IndexedDB（`bookmark-preview` 資料庫） |
| 偏好設定（顯示密度、預覽圖來源、觸發字串等） | `storage.local` |
| 個別書籤選的預覽方式（「改用網站圖示／頁面預覽」） | `storage.local`，以網址的雜湊值（SHA-256）為鍵，不存網址本身；隱私書籤的選擇存在加密的隱私空間裡 |
| 隱私空間（加密後的書籤與預覽圖） | `storage.local`，以 AES-GCM 加密 |
| 書籤群組與定下來的欄數（全頁瀏覽） | `storage.local`，預設也存一份在 `storage.sync`（見下文） |

解密金鑰只存在背景程式的記憶體中，不會寫入磁碟。上鎖、關閉瀏覽器、隔一段時間沒有使用隱私空間、離開電腦、或關掉最後一個擴充套件頁面之後，金鑰即消失。

## 什麼情況下資料會離開你的裝置

有三種。三種情況下開發者都收不到任何東西。

**1. 你自己開啟「把加密副本放進 Firefox 同步」。**
開啟後，隱私空間的**密文**會透過 `storage.sync` 存進你自己的 Firefox 帳號，以便在你自己的其他裝置上使用。這條路徑：

- 送出去的是加密後的位元組，Mozilla 的同步伺服器與開發者都無法解讀。
- 解密需要你的主密碼或救援金鑰，兩者都不會被同步。
- 預設是關閉的，可以隨時在設定頁關掉。

**2. 書籤群組透過 Firefox 同步 —— 預設開啟。**
你在全頁瀏覽建立的群組（名稱、顏色、哪些書籤屬於它，以 Firefox 自己的書籤代號表示）與定下來的欄數存在 `storage.sync`，讓你的其他裝置看到同樣的群組。這條路徑：

- 只有在你登入 Firefox 同步、並且有同步附加元件資料時才會離開這台裝置；否則 `storage.sync` 只留在本機。
- **這個擴充套件不另外加密它**。它的傳送與保存方式和 Firefox 同步你的書籤本身一樣 —— 群組名稱與書籤標題是同一類資訊，所以預設開啟。裡面附帶一個隨機的裝置代號，用來在你的幾台裝置之間決定哪份較新。
- 不包含任何隱私空間的內容。隱私空間裡的群組屬於隱私空間，只會以密文的形式隨第 1 種情況同步。
- 固定佔用同步空間的 20 KB，可以在設定頁「同步書籤的排列與群組」關掉；關掉時也會把這份資料從同步空間移除。

**3. 抓取預覽圖時，向你已加入書籤的網站發出請求。**
「補抓預覽圖」與「重新抓預覽圖」會連線到**該書籤本身的網址**，讀取頁面上的封面圖（`og:image` 之類）；書籤指的是整個網站時，則是那個網站自己的圖示與 Web App manifest。這是一般的網頁請求，等同你自己打開那個網址；請求只送到那個網站，不經過任何中介伺服器。那個頁面正開著時，抓圖片的那一次請求是**在該頁面裡**發出的，因此會帶著該頁面載入那張圖時用的同一份 cookie —— 有些網站的圖片只有這樣才拿得到。不會送到任何其他地方。你可以在設定頁的「不擷取的網域」把特定網站排除。

## 網頁截圖

擷取畫面用的是 Firefox 提供的 `tabs.captureVisibleTab`，只會擷取**你自己正在瀏覽的分頁**，而且只在該網址是你的書籤時才儲存。截圖存在本機 IndexedDB，不會上傳。

## 瀏覽記錄

只有在你把書籤移入隱私空間、並且勾選「同時清除該網址的瀏覽記錄」時，才會用到瀏覽記錄權限，而且**只做刪除**：把該網址從瀏覽記錄中移除，讓它不再出現在網址列的自動完成中。這個擴充套件不會讀取、儲存或傳送你的瀏覽記錄。

## 如何刪除資料

- **預覽圖**：設定頁 →「清除所有預覽圖」。
- **隱私空間**：解鎖後，側邊欄隱私分頁的 ⋯ 選單 →「刪除整個隱私空間…」，或設定頁「危險操作」（不可復原）。
- **隱私空間的雲端副本**：設定頁 →「移除雲端副本並關閉同步」。
- **同步的書籤群組**：設定頁 → 取消勾選「同步書籤的排列與群組」（從同步空間移除；這台裝置自己的那份保留）。
- **全部**：移除這個擴充套件，Firefox 會連同它的所有本機儲存一起刪掉。
