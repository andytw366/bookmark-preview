設計語言

方向：「像 Firefox 自己的面板」。系統字型、中性冷灰、只有一個藍色強調色；淺／深色用同一組變數名，跟著系統切換。全部以 CSS 變數定義，React＋純 CSS 可以直接套用。

色彩

同一個變數名，兩種主題各一組值。淺色接近 Firefox 淺色主題的面板，深色接近 Firefox 深色主題。

強調色與語意色的用法

藍色 accent：只有 4 種用途
1. 目前選取（分頁、選取列、勾選）
2. 每個畫面最多一顆主要按鈕
3. 鍵盤焦點框（2px）
4. 文字連結
紅色 danger：不可逆
刪除、清除、重新產生金鑰、解除隱私空間。
選單裡一律放最後一組；設定頁集中到「危險操作」。
不要用強調色的地方
分段控制的選中（用浮起的白底，像原生）、裝飾線、圖示預設色、群組框（群組有自己的 6 色）。
群組 6 色 框線用原色、底色用 8% 混色（color-mix）、標籤文字用 --on-g，深色主題自動換成亮一階的版本。

字級

系統字型（Windows：Segoe UI＋微軟正黑體；macOS：系統字＋蘋方）。中文行高 1.5。英文字串比中文長 1.5–2 倍，所以文字一律單行＋刪節號，不靠固定寬度。

落地用 CSS 變數

放在 :root，深色用 media query 覆寫同名變數。側邊欄與全頁瀏覽共用。
