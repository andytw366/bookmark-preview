### 怎麼讀 `.dc.html`

- 它是設計工具的格式，**不是**要直接搬進專案的程式碼。
- `<sc-for list="{{items}}" as="b">` = 迴圈；`<sc-if value="{{b.isIcon}}">` = 條件；`{{b.title}}` = 資料欄位。
- 設計稿內的 `.th` / `.th.dark` 是為了在同一張畫布並排淺深色；實作時請改用 `tokens.css` 的 `:root` ＋ `prefers-color-scheme`。
- 頂端灰色的「書籤預覽 ⌄ ✕」是 Firefox 原生側邊欄標題列，畫出來只是示意，**不要實作**。

## 做法

1. 加入 `tokens.css`，把現有元件的顏色、字級、間距、圓角、陰影全部換成變數。
2. 先做共用元件，再套到側邊欄與全頁瀏覽：
   - `IconButton`（28px，全頁 32px；必帶 `aria-label` 與 `title`）
   - `SegmentedControl`（選中塊是浮起的 `--surface`，不用強調色）
   - `Menu` / `MenuItem` / `MenuSeparator` / `MenuHeader`（寬 208px，項目高 28px，16px 圖示，文字不換行）
   - `Checkbox`、`Radio`、`Switch`
   - `Thumb`（預覽圖底板，見下）
   - `Group`（群組框）
3. 再逐畫面改：側邊欄 → 全頁瀏覽 → 設定頁。
4. 功能一個都不能少；下面每個選單都列出完整項目。

## 設計語言重點（完整數值在 `tokens.css`、`design/Main.dc.html`）

- 方向：像 Firefox 自己的面板。系統字型、中性冷灰、只用一個藍色強調色。
- 強調色只有 4 種用途：目前選取、每個畫面最多一顆主要按鈕、鍵盤焦點框、文字連結。
- 紅色只給不可逆操作：刪除、清除、重新產生金鑰、刪除隱私空間。在選單裡永遠放最後一組。
- 卡片平常不加陰影，靠底色區分；hover 才換成 `--surface-2`。
- 文字一律單行＋刪節號（英文字串會長 1.5–2 倍）。

### 預覽圖底板（`Thumb`）

所有預覽圖都放進同一個底板：大卡是 16:9，小列是 40×40。底板決定尺寸，圖只決定怎麼放進去。

| 種類 | 放法 |
|---|---|
| 封面圖 | `object-fit: contain`，不裁切，兩側露出 `--plate` |
| 網頁截圖 | `object-fit: cover; object-position: top`，裁成 16:9 |
| 網站圖示 | 底板素色，圖示寬 34%（小列 24px），`border-radius: 20%`，置中 |
| 字母色卡 | 整塊填色＋白字；顏色由網域雜湊，從 8 色色票挑（每色對白字都要達 4.5:1） |

### 隱藏模式＋上鎖時的顯示規則（Andy 已決定）

現況問題（目前設定頁沒有參考「隱藏模式」，上鎖時會露餡）：
- 隱私空間區塊顯示「狀態：已上鎖」；沒有隱私空間時是建立表單，兩者一看就分得出來。
- 出現「放棄這台裝置上的隱私空間」一節（只有本機有隱私空間才會出現）。
- 備份區顯示「這台裝置已經有隱私空間但目前上鎖」。
- 同步區顯示雲端副本的狀態、容量與上次同步時間。
- 救援金鑰與更改主密碼本來就只在解鎖後出現；上鎖時顯示「需要先解鎖」，和沒有隱私空間時相同（這部分沒問題）。

規則：

| 「入口」設定 | 隱私空間狀態 | 設定頁顯示 |
|---|---|---|
| 隱藏 | 上鎖 | 只顯示下表中「顯示」的項目 |
| 隱藏 | 已解鎖 | 全部顯示 |
| 顯示分頁 | 任何狀態 | 全部顯示（維持現狀） |

| 項目 | 隱藏＋上鎖時 |
|---|---|
| 預覽圖整組 | 顯示 |
| 同步：書籤的排列與群組 | 顯示 |
| 隱私空間：入口 | 顯示 |
| 隱私空間：觸發字串（含目前的值） | 顯示。這兩節不論有沒有建立隱私空間都存在，不會透露有沒有在用；忘了觸發字串也能從這裡查回來。真正的防線是密碼 |
| 隱私空間：狀態標籤、說明文字「移出、刪除單筆隱私書籤…」 | 不顯示 |
| 移出時的預設資料夾 | 不顯示 |

要求：
- 上鎖時的設定頁必須和「從沒建立過隱私空間」的人看到的一樣：不能留空位，也不能有「還有更多設定」「解鎖以查看」之類的暗示。
- 設定頁開著時，狀態改變要即時反映：解鎖後隱藏的區塊立刻出現；上鎖（手動或自動）後立刻消失。
- 設計稿 `Settings.dc.html` 畫的是「已解鎖」的完整狀態。

建立隱私空間（Andy 已決定）：
- 入口是「隱藏」：設定頁在任何狀態（沒有隱私空間、上鎖、已解鎖）都不顯示「建立隱私空間」表單。建立一律從側邊欄搜尋框輸入觸發字串開始。
  - 現有的側邊欄密碼框在還沒有隱私空間時本來就會顯示建立表單，不用新做；只要套上新的外觀（03 的密碼框樣式）。
- 入口是「顯示分頁」：維持現狀，建立表單照常出現在設定頁。
- 設定頁「觸發字串」一節的說明文字改成：「在側邊欄搜尋框輸入這段文字，即可建立或打開隱私空間。」這句話對有沒有隱私空間的人都成立，不會洩漏狀態。

數字也不能露餡（由上面的規則推導，實作時一併處理）：
- 隱藏＋上鎖時，所有看得到的數字都不能包含隱私書籤，例如：設定頁「儲存空間」的預覽圖張數與容量、補抓進度「7 / 8」、資料夾的書籤數。
- 否則別人可以拿這些數字和看得到的書籤數比對，推算出有隱私書籤。

## 額外 UX 建議（設計稿沒畫，可另開工作）

- 所有圖示鈕都要有 `aria-label`＋`title` 提示。
- 鍵盤：`/` 聚焦搜尋、`Esc` 結束選取或關閉選單、`Enter` 開啟、方向鍵在清單與選單中移動。
- 刪除改成「先刪、5 秒內可復原」的提示，取代每次都跳確認視窗（不可逆的隱私操作仍要確認）。
- 選單位置要做邊界偵測：靠近側邊欄底部時往上開。
